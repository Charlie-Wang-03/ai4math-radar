# 隐私说明

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 2026-09-30 |
| 运营主体 | AI4Math Radar 开源项目维护者 |
| 隐私事务联系 | 站内反馈页；公开 GitHub Issue 不应包含个人敏感信息 |

AI4Math Radar 默认无需注册即可浏览。项目不会出售个人信息，也不以广告画像为目的收集访问者数据。

## 1. 浏览器本地数据

收藏、已读记录、主题偏好和反馈草稿等客户端状态会按产品实现保存在浏览器本地。清除浏览器数据后这些信息可能消失，默认不会跨设备同步。

## 2. 反馈

如果你主动提交反馈，服务器可能处理你填写的内容、选填联系方式、提交页面地址，以及你主动附带的截图或其他材料。为防止滥用，系统可能保存用于限流的不可逆网络标识，而不是直接把原始网络地址作为产品资料展示。

请不要在反馈或公开 GitHub Issue 中提交密码、API key、私人通信、身份证件或其他不必要的敏感信息。

## 3. 服务器与网络日志

AI4Math Radar 本身默认不启用面向广告或营销的访客分析。正式部署基础设施、反向代理、CDN 或托管平台仍可能为了安全、可用性和故障排查记录必要的访问日志，例如网络地址、请求时间、路径、状态码和浏览器类别。

正式部署计划使用 Railway 等基础设施服务承载应用和数据库时，相应平台会按其服务条款处理运行所需的基础设施数据。项目不会因为使用托管平台而向广告商出售访问数据。

## 4. 第三方来源

本站主要展示第三方研究内容的摘要和链接。点击原文后会离开 AI4Math Radar，之后适用目标网站自己的隐私政策和 Cookie 规则。

## 5. 数据保留与删除请求

反馈资料和运行日志只在维护、安全与问题排查所需范围内保留；实际保留时间可能随托管平台配置调整。如果你希望查询、更正或删除自己主动提交的反馈资料，可通过站内反馈页联系我们。若需要私下处理，不要在公开 Issue 中附上个人敏感信息。

## 6. 变更

如果站点未来新增账号系统、第三方统计、支付、个性化画像或其他会显著改变个人数据处理方式的功能，应在启用前更新本说明。
