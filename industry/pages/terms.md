AI4Math Radar 聚合公开信源，并使用模型生成中文摘要、结构化信息与研究情报索引。原文版权归各来源所有；重要研究结论、数学证明和事实请以原始论文、项目页面或其他一手来源为准。

## 1. 内容与版权

本站展示的标题、摘要、推荐理由、分类和事件关系可能由模型生成或辅助生成，可能存在遗漏或错误。AI4Math Radar 不声称拥有第三方原文版权；默认只展示摘要、必要的元数据和原文链接，只有在来源许可或明确允许时才展示更多内容。

仓库代码的许可见 `LICENSE`；站点聚合到的第三方内容、商标、论文、图片和数据不因代码许可证而改变其原有权利状态。

## 2. 数学与研究结论

本站不是数学证明的权威认证机构，也不保证任何“已证明”“已验证”“解决开放问题”等表述最终成立。系统会尽量区分作者主张、专家核验和形式系统验证，但读者在引用、研究决策或公开传播前仍应回到原始证据。

## 3. 来源方更正、下架与署名

如果你是来源方或权利人，希望更正摘要、补充署名、调整展示方式或下架相关内容，可通过站内反馈页联系我们。也可在 GitHub 仓库提交不含个人敏感信息的 Issue；需要私下沟通时，请先请求私密联系方式，不要在公开 Issue 中披露敏感材料。

## 4. 网站、RSS、API 与 MCP 的使用

网站、RSS、公开 API 与 MCP 主要用于个人阅读、研究、教育和合理的组织内部使用。自动访问时请遵守缓存头、速率限制和 `Retry-After`，不要高并发抓取、绕过访问控制或故意影响服务可用性。

如果你要公开再分发大量聚合结果、把第三方内容用于商业产品，或进行可能超出合理使用范围的复制，请自行确认相关来源许可并承担相应责任。

## 5. 禁止事项

不得利用本站接口从事违法活动、攻击服务、绕过安全限制、批量收集非公开信息，或把模型生成内容伪装成已经得到独立数学验证的事实。

## 6. 可用性与变更

本站按“现状”提供，不承诺持续可用、固定更新频率或无错误。研究范围、信源、模型、评分规则和接口可能随项目演进调整；对外兼容面发生重要变化时会尽量在仓库或站点更新记录中说明。
