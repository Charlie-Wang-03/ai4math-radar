## Method

- For all 34 rows: open the **exact Hexagon v1** linked by the canonical record, verify title and the publication calendar **day**. All 34 v1 pages supply day/date but do not expose the **v1 public announcement instant** in a human-verifiable timestamp.
- Cross-check claim-matched, explicitly cited GitHub Release pages using GitHub **releases/tags** metadata (the `published_at` field) instead of a Git commit author's timestamp. A matching Release predating a Hexagon v1 day is **earlier public evidence of the same result**; it is not a verified Hexagon first-public clock. Same-day releases have less certain chronology relative to Hexagon and are kept as evidence-only.
- Palomar registration time denotes the **proof artifact**, not necessarily the manuscript; a registration dated before the paper is an earlier milestone candidate but may not encompass the same mathematical claims.
- **No new `publishedAt` exact-minute upgrades**, because no primary evidence established the Hexagon v1 release's precise public clock. Retain `publishedAt=YYYY-MM-DDT00:00:00.000Z` with UI `未注明` and stable IDs for all 34 records.
- A `chronology.earliestVerifiedPublic` record means **earliest independently inspected matching public artifact**, not a proof of the absolute earliest publication nor mathematical correctness. `chronology.milestone` specifies the later *Hexagon paper-release* highlighted by this news.
- No full source-code rebuild or Lean mathematical audit was conducted; evidence here is restricted to temporal provenance.

## Results and risk register

- **34 / 34** outstanding records reviewed; together with Batch 02's 15, the period **Oct 20–23 now has 49 / 49 source-history audits**.
- **11** of these 34 have claim-matched **earlier** GitHub Release timestamps, added with **optional chronology** provenance metadata. No original content, `id`, `publishedAt`, source URL, category, score, or `discoveredAt` was changed.
- **3** have exact GitHub artifact release timestamps **on the same UTC day** as Hexagon v1 (KnotInfo, abelian squares, Welch), which do **not** determine relative ordering without Hexagon's exact publish instant. Kept in ledger only.
- **20** have only Hexagon v1 calendar-day evidence or related proofs/releases with insufficient clock semantics. They remain correctly **未注明**.
- Notable cross-milestone scope risks: the [five-body paper](https://hexagonmath.org/2610.00467v1) reports **private** expert circulation Oct 6 (not proof of publication); [Mislan unistationarity](https://hexagonmath.org/2610.00437v1) links a September Palomar proof registration; [fault detection](https://hexagonmath.org/2610.00503v1) links an Oct19 Palomar registration. These are not automatically a first public clock for the Hexagon manuscript.
- The Hexagon [publication policy](https://hexagonmath.org/about) states that new deposits become **public after moderation/acceptance**. Therefore the submitter's internal submission or asset build timestamps must never be substituted for an independently verified public first-release instant.
- Links to GitHub Release in this ledger support **when a source artifact was public**, not validity of a submitted mathematical claim, and not the nonexistence of earlier undiscovered releases.
